# Thirdparty Software Packages

A number of thirdparty software packages have been used in this project, and this document provides versioning, licensing, copyright and source information.


| Package      | Description |
| ----------- | ----------- |
| arduiono-esp32| Core libraries for ESP32 devices with Arduino IDE/cli support|
| AsyncTCP | Asynchronous TCP networking layer|
| DallasTemperature | Maxim temperature device support|
| ESP Async Webserver | Asynchronous web server|
| ModbusMaster | Modbus master controller|
| modbus-esp8266| Modbus slave device support|
| OneWire | One Wire communications protocol|
| ReadyMail | Email sending library|
